# mini-order-payments-web

Minimal Next.js (App Router) frontend for the mini-order-payments workshop.

## Setup

```bash
npm install
npm run dev
```

App runs on [http://localhost:3001](http://localhost:3001). Orders page: [http://localhost:3001/orders](http://localhost:3001/orders).

Expects the Nest API at `http://localhost:3000`.
